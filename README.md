# 时段模型调度（model-scheduler）

一个通用的"时段 → 模型"调度器插件：按一天中的不同时间段，让麦麦使用不同的模型生成回复。

## 引言

DeepSeek 官方 API 提供错峰定价：**00:30 ~ 08:30 时段调用价格为半价**。如果你的麦麦在深夜依然活跃，把这段时间的回复切到 DeepSeek，可以显著降低 token 开销。

但本插件并不只是为 DeepSeek 而生——它是**通用的**。任何"按时段换模型"的需求都适用，例如：

- 夜间错峰：00:30 ~ 08:30 使用便宜/错峰模型（如 DeepSeek）；
- 深夜安静时段：22:00 ~ 06:00 切换到低速率、更适合长文生成的模型；
- 白天高峰：切回主力模型保证响应速度；
- 或者反过来：白天用便宜模型，晚间用高质量模型。

只要模型已在麦麦模型配置页中定义过，就可以按时间段任意指派。

## 工作原理

插件基于钩子 **`maisaka.replyer.before_request`** 工作：

1. 每轮回复生成前，该钩子被触发；
2. 插件读取当前本地时间（按 `timezone_offset` 换算），逐条匹配 `[rules]` 中的时段规则；
3. 若某条规则命中，插件通过修改 `model_name` 参数，指定该时段使用的模型；
4. 在钩子中指定 `model_name` 会**绕过**麦麦原生的随机/均衡等模型选择策略，直接使用指定模型；
5. 返回的 `modified_kwargs` 会**完整替换**原请求参数（其余参数原样透传）；
6. 若没有任何规则命中，插件不做任何干预，麦麦照常走原有模型策略（除非配置了兜底模型）。

安全设计：

- 插件开启但没配置任何规则 = **零干预**，麦麦行为与未安装本插件时完全一致；
- 插件自身出错时只记录日志、**不阻断回复**（错误策略 `ErrorPolicy.SKIP`），最坏情况等同于插件不存在。

## 安装

1. 将整个插件文件夹（`_manifest.json`、`plugin.py` 等）复制到麦麦的 `plugins` 目录下。`config.toml` 无需自带：首次加载时 Runner 会自动生成，也可以复制 `config.example.toml` 为 `config.toml` 后再修改；
2. 重启麦麦；
3. 在日志中确认插件加载成功；
4. 按需修改 `config.toml`（见下节），配置热更新即时生效，无需重启。

## 配置说明

配置文件为插件目录下的 `config.toml`，分为三节。

### `[plugin]` —— 插件总开关

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | 布尔 | `true` | 插件总开关，`false` 时完全不干预 |
| `config_version` | 字符串 | — | 配置文件版本号（与插件版本同步），请勿随意修改 |

### `[rules]` —— 时段规则

`rules` 是一个规则列表，每条规则包含以下字段（多条规则同时命中时，取**第一条**命中的）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `enabled` | 布尔 | 是 | 该条规则是否启用 |
| `note` | 字符串 | 否 | 备注说明，仅用于人类阅读，不影响行为 |
| `start` | `HH:MM` | 是 | 时段开始时间 |
| `end` | `HH:MM` | 是 | 时段结束时间，支持跨午夜区间（如 `22:00` ~ `06:00`） |
| `model_name` | 字符串 | 是 | 该时段使用的模型名，**须先在麦麦模型配置页定义过，名字须完全一致** |
| `task_names` | 字符串列表 | 否 | 生效任务，**仅 `replyer` 有效**（本插件作用于回复生成链路，官方钩子不支持为 planner 等其他任务指定模型；填了其他任务名不会生效，加载时会有警告日志） |
| `use_global_timezone` | 布尔 | `true` | 是否跟随「通用」页的全局时区偏移（默认开启）。关闭后本条规则改用下方 `timezone_offset` |
| `timezone_offset` | 数值 | `8` | 本规则的时区偏移（小时），支持小数（半小时区如 `5.5`）。**仅当 `use_global_timezone=false` 时生效**，用于不同厂商错峰时段按不同时区公布的场景（如某海外厂商按 UTC 公布则填 `0`）。注意：TOML 不支持 null，此字段始终有值，是否生效由 `use_global_timezone` 决定 |

默认预置 1 条示例规则：`00:30 ~ 08:30` 使用 DeepSeek（官方错峰半价时段），可按需修改或删除。

### `[general]` —— 通用设置

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `timezone_offset` | 数值 | `8` | 全局时区偏移（小时），支持小数（半小时区如 `5.5`），未单独设置时区的规则按此判断。北京时间为 `8` |
| `default_model_name` | 字符串 | `""` | 兜底模型：无规则命中时使用的模型。留空 = 不干预，走麦麦原策略 |
| `log_every_switch` | 布尔 | — | 是否在每次模型切换时记录日志 |

### 多规则示例

```toml
[[rules.rules]]
enabled = true
note = "深夜错峰：DeepSeek 官方 00:30~08:30 半价（北京时间）"
start = "00:30"
end = "08:30"
model_name = "deepseek-v4-flash"
task_names = ["replyer"]

[[rules.rules]]
enabled = true
note = "夜间安静时段：换用适合长文的模型"
start = "22:00"
end = "06:00"
model_name = "某夜间模型"
task_names = ["replyer"]

[[rules.rules]]
enabled = true
note = "某海外厂商：错峰时段按 UTC 公布（关闭跟随全局，本规则按 UTC 解释，与其他规则互不影响）"
start = "01:00"
end = "05:00"
model_name = "某海外模型"
task_names = ["replyer"]
use_global_timezone = false
timezone_offset = 0
```

> 注意：多条规则同时命中时按顺序取第一条。上例中 `00:30 ~ 06:00` 同时落在两条规则内，实际使用规则 1 的 `deepseek-v4-flash`。第三条规则关闭了「跟随全局时区」并设 `timezone_offset = 0`，其时间按 UTC 解释，与全局的北京时间互不干扰——这正适合不同厂商错峰时段公布时区不一致的场景。

## 使用与验证

### 看日志确认生效

规则命中时，麦麦日志中会出现类似内容：

```
时段命中 → 指定模型 deepseek-v4-flash
```

### 快速测试方法

不想等到半夜验证？把规则时间临时改成覆盖当前时间即可。例如现在是 15:20，可临时改为：

```toml
start = "15:00"
end = "16:00"
```

保存 `config.toml` 后热更新即时生效，在群里发一条消息触发回复，观察日志与回复所用模型。验证完成后改回原时间即可。

### 常见问题（FAQ）

| 问题 | 解答 |
| --- | --- |
| 填了模型名但没生效？ | 检查该模型是否已在**麦麦模型配置页**定义过；`model_name` 必须与配置页中的名字**完全一致**（区分大小写、前后空格）。 |
| 跨午夜时段怎么写？ | 直接写 `start = "22:00"`、`end = "06:00"` 即可，插件原生支持跨午夜区间。 |
| 不想干预某些时段怎么办？ | 只要不写覆盖该时段的规则即可——无规则命中的时段默认不干预。也可为个别时段显式指定模型，其余时段留空。 |
| 插件开着但没配规则会怎样？ | **零干预**。麦麦的模型选择行为与未安装本插件时完全一致（若 `default_model_name` 留空）。 |
| 多条规则都命中用哪条？ | 按配置顺序取**第一条**命中的规则。 |
| 改了配置要重启吗？ | 改 `config.toml` 即时生效。改 `plugin.py` 后需在 WebUI 插件管理中重载插件（或重启麦麦）。仅改 `_manifest.json` 必须完整重启麦麦。 |
| 手动编辑 config.toml 后插件报 TOML 解析错误？ | 多半是文件带了 UTF-8 BOM：PowerShell 的 `Set-Content -Encoding UTF8` 会写入 BOM，请用无 BOM 的 UTF-8 保存（VS Code / 记事本另存为 UTF-8 即可）。 |
| 插件出错了会影响回复吗？ | 不会。插件出错只记日志不阻断回复（`ErrorPolicy.SKIP`），最坏情况等同于插件不存在。 |

## 注意事项

- `model_name` 指向的模型必须**先在麦麦模型配置页定义**，否则指派无效或导致请求失败；
- 模型名须与配置页**完全一致**；
- 本插件仅作用于 **replyer（回复生成）** 任务，planner 等其他任务的模型不受影响（官方钩子不支持为其指定模型）；
- 钩子中指定 `model_name` 会**绕过**麦麦原生的随机/均衡模型策略；
- `timezone_offset`（通用页）按你所在时区设置，北京时间为 `8`；某条规则的时间需要按其他时区解释时，关闭该规则的 `use_global_timezone` 并设 `timezone_offset`（支持半小时区如 `5.5`）；
- 指定模型请求失败后的重试轮，插件不再指名（交还麦麦的策略兜底），避免反复请求刚失败的模型；
- 错峰时段的边界以模型服务商官方公告为准（如 DeepSeek 半价时段如有调整，请同步修改规则时间）；
- 建议为每条规则填写 `note` 备注字段，方便日后维护。

## 卸载

1. 将 `[plugin]` 的 `enabled` 设为 `false`（或直接停用插件）；
2. 确认麦麦回复恢复正常后，删除插件文件夹；
3. 重启麦麦完成卸载。

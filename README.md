# 峰谷时段省钱调度（model-scheduler）

一个通用的"时段 → 模型"调度器插件：像峰谷电价一样，按一天中的不同时间段（还可限定星期几），让麦麦自动换用不同的模型生成回复——空闲"谷"时用便宜/错峰模型省钱，高峰"峰"时切备用模型避贵。

---

# ⚡ 配置项逐项说明（先看这里）

> 本节按 WebUI 配置页顺序，**每一个选项**逐一讲：是什么、该填什么、常见错误。

## 开始前：先搞懂「模型名」是什么（90% 的问题出在这）

本插件所有地方要填的「模型名」，都指**麦麦模型配置页里你自己给模型起的名字**——

打开麦麦的 `config/model_config.toml`（或 WebUI 模型配置页），你会看到类似：

```toml
[[models]]
name = "deepseek-v4-flash"    # ← 就是这个！你起的名字
```

- ✅ 正确填写：`deepseek-v4-flash`（和 `name =` 后面那个词**一字不差**，区分大小写）
- ❌ 错误填写：火山/DeepSeek 官网的模型 API 编号、没在配置页定义过的名字

**自检方法**：你填的名字，必须能在模型配置页里原样找到。找不到 = 无效。

### 💡 进阶：可以指定任何已定义的模型，不限于回复默认列表

「模型名」可以从模型池里**任意选**——哪怕那个模型本来不在 replyer 的默认列表里。

**举例**：假设 replyer 的默认列表只配了 `deepseek-v4-pro`，而模型池里另外定义了 `deepseek-v4-flash`。想让深夜回复走便宜的 flash 省钱？只要加一条规则：

- 生效星期：留空（每天）
- 时间：`23:00` 到 `07:00`（跨午夜）
- 模型名：`deepseek-v4-flash`（填**名字**，虽然它不在 replyer 默认列表里）

生效后：深夜回复自动走 flash（省钱），白天不在规则时间内 → 插件零干预，照常走 pro。**实测确认**：插件指定后，宿主会按名字到模型池里取对应的地址和密钥发起请求——不受 replyer 默认列表限制。

这也是一种省钱思路：**贵模型只留给白天活跃时段，夜间安静时段自动切便宜模型**。

## 1.「插件」页

### 插件总开关

整个插件的电源开关。关闭 = 插件完全不干预，麦麦的模型选择和没装本插件时一模一样。

## 2.「时段规则」页（核心功能）

每条规则回答一个问题：**「星期几的几点到几点，把回复换成哪个模型」**。
多条规则同时命中时，**按列表顺序取第一条命中的**（调优先级 = 调顺序）。

### 启用

这一条规则要不要生效。临时停用某条规则时关掉它即可，不用删除。

### 备注

只给你自己看的名字。建议写清意图，例如：`工作日早高峰切备用模型`。

### 开始时间 / 结束时间

| 情况 | 写法 |
| --- | --- |
| 常规区间 | `09:00` 到 `12:00` = 上午 9 点到 12 点生效（`HH:MM` 24 小时制） |
| **跨午夜** | `22:00` 到 `06:00` 直接这样写 = 晚 10 点到早 6 点，插件原生支持 |
| **全天** | 开始和结束填一样（如都是 `00:00`）|

### 模型名 ★ 最容易填错的项

| | 说明 |
| --- | --- |
| 填什么 | 模型配置页里那个模型的**名字**（见本节开头），如 `deepseek-v4-flash` |
| 留空 | 这条规则整体无效（等于没写） |
| 常见错误 | ① 填了官网 API 编号但配置页没定义 ② 名字抄错一个字母 ③ 前后多了空格 |

### 生效任务 ★ 只有 replyer 有效

点「添加项目」后填 `replyer`（这一一个词）。

- 本插件挂在**回复生成链路**上，官方钩子只有 replyer 会触发
- 填 `planner`、`utils` 等其他任务名**不会生效**（加载时会打警告日志提醒）
- 留空 = 这条规则整体无效

### 生效星期 ★ 填法对照表

控制规则在星期几生效。点「添加项目」后，**每个项目里填一个词**：

| 你想… | 项目里填 |
| --- | --- |
| 每天都生效 | **什么都不填**（列表留空 = 每天） |
| 只在工作日（周一-周五） | 加 1 项：`weekday` |
| 只在周末 | 加 1 项：`weekend` |
| 只要周一、周三、周五 | 加 3 项：`mon`、`wed`、`fri` |
| 用中文也行 | `周一` `周二` … `周日`（或 `monday` `tuesday` … `sunday` 全拼） |

合法词（**每个项目只能填一个**）：`weekday` / `weekend` / `mon`、`tue`、`wed`、`thu`、`fri`、`sat`、`sun` / `周一`、`周二`…`周日` / `monday`、`tuesday`…`sunday`（大小写不限）。

> ⚠️ **不要填 `mon-sun`、`周一-周日` 这类带连字符的写法**——它会被当成一个无法识别的词而失效（不报错，该规则会退化成「每天生效」上的其他条件）。想涵盖一整周请直接留空；想指定几天就分开填多项。

### 跟随全局时区

保持默认**开启**（用「通用」页的时区，国内 = 北京时间）。仅当目标厂商**按别的时区**公布高峰时段时才关闭（见下方时区偏移的例子）。

### 时区偏移（小时）

仅当「跟随全局时区」**关闭**时有用。

**关键：你填的是「模型厂商公布错峰时段时用的那个时区」，换算由插件自动完成，不需要你自己算。**

原理：插件拿当前 UTC 时间，加上你填的偏移，得到"该厂商时区的现在"，再判断是否落在你写的时间区间里。

例子——假设某海外模型厂商公告"UTC+2 时区的高峰为 09:00-18:00"：

1. 关闭这条规则的「跟随全局时区」
2. 时区偏移填 `2`
3. 时间区间照抄厂商公告：`09:00` 到 `18:00`

之后无论你在世界哪个角落，插件都会自动对表：北京下午 3 点（= 该时区上午 9 点）→ 规则命中。你完全不需要把 09:00-18:00 换算成北京时间再填。

## 3.「通用」页

### 时区偏移（小时）

全局默认时区，**所有「跟随全局时区=开启」的规则都按它判断**——设一次即可，无需每条规则重复填。国内用户保持 `8` 不动。

什么时候需要动它：只有当某条规则要按**其他时区**解释（海外厂商按非北京时间公布高峰）时，才去那条规则里关闭「跟随全局时区」并单独设偏移——「通用」这里保持不动，其他规则不受影响。

### 兜底模型名

所有规则都没命中时强制使用的模型。

- **留空（推荐）** = 不命中就不干预，麦麦走自己的模型策略
- 填了 = 全时段被本插件接管（一般不需要）

### 记录切换日志

保持开启：每次实际切换模型打一行日志 `[峰谷省钱] 时段命中 → 指定模型 xxx`，方便确认插件在工作。

# 🧪 快速验证

不想等到对应时段才验证？把某条规则的时间临时改成**覆盖当前时间**（如现在 14:20，改成 `14:00`-`15:00`），保存（即时生效），发条消息触发回复，日志出现 `[峰谷省钱] 时段命中 → 指定模型 xxx` 即在工作。验证完改回原时间。

# 📌 引言

DeepSeek 官方 API 提供错峰定价：**空闲时段价格为高峰时段的一半**。官方高峰时段为**北京时间周一至周五 9:00-12:00、14:00-18:00**，其余时间（含工作日的早/晚/午休与整个周末）均为空闲时段。若你的麦麦在这些空闲时段保持活跃，让回复走 DeepSeek 即可显著降低 token 开销；两个工作日高峰段切到备用便宜模型，避开标准价。

本插件通用，任何"按时段换模型"的需求都适用：夜间切长文模型、周末与工作日用不同模型、白天便宜晚间高质量……只要模型已在麦麦模型配置页中定义过，就可以按「星期 + 时间段」任意指派。

## 工作原理

插件基于钩子 **`maisaka.replyer.before_request`** 工作：

1. 每轮回复生成前，该钩子被触发；
2. 插件读取当前时间（按规则时区换算），结合规则的生效星期与时间区间逐条匹配；
3. 若某条规则命中，插件通过修改 `model_name` 参数，指定该时段使用的模型；
4. 在钩子中指定 `model_name` 会**绕过**麦麦原生的随机/均衡等模型选择策略，直接使用指定模型；
5. 返回的 `modified_kwargs` 会**完整替换**原请求参数（其余参数原样透传）；
6. 若没有任何规则命中，插件不做任何干预，麦麦照常走原有模型策略（除非配置了兜底模型）。

安全设计：

- 插件开启但没配置任何规则 = **零干预**，麦麦行为与未安装本插件时完全一致；
- 插件自身出错时只记录日志、**不阻断回复**（错误策略 `ErrorPolicy.SKIP`），最坏情况等同于插件不存在。

## 安装

1. 将整个插件文件夹（`_manifest.json`、`plugin.py` 等）复制到麦麦的 `plugins` 目录下。`config.toml` 无需自带：首次加载时 Runner 会自动生成，也可以复制 `config.example.toml` 为 `config.toml` 后再修改；
2. 重启麦麦；
3. 在日志中确认插件加载成功；
4. 按需修改 `config.toml`（见上方逐项说明），配置热更新即时生效，无需重启。

## 多规则示例

```toml
# DeepSeek 官方错峰（高峰=工作日 9:00-12:00、14:00-18:00 标准价，其余空闲半价）：
# 候选池默认放 DeepSeek（空闲时段插件零干预=半价），下面两条在工作日高峰把回复切到备用模型
[[rules.rules]]
enabled = true
note = "工作日早高峰 9:00-12:00 → 备用模型"
start = "09:00"
end = "12:00"
model_name = "某备用模型"          # ← 替换为你的便宜模型名
task_names = ["replyer"]
days_of_week = ["weekday"]
use_global_timezone = true
timezone_offset = 8.0

[[rules.rules]]
enabled = true
note = "工作日下午高峰 14:00-18:00 → 备用模型"
start = "14:00"
end = "18:00"
model_name = "某备用模型"
task_names = ["replyer"]
days_of_week = ["weekday"]

# 其他用法：周末整日切一个模型（跨午夜写法），或某海外厂商按 UTC 计（关闭跟随全局）
[[rules.rules]]
enabled = true
note = "周末深夜跨午夜：用适合长文的模型"
start = "22:00"
end = "06:00"
model_name = "某夜间模型"
task_names = ["replyer"]
days_of_week = ["weekend"]
```

> 注意：多条规则同时命中时按顺序取第一条。第三条规则关闭了「跟随全局时区」并设 `timezone_offset = 0`，其时间按 UTC 解释，与全局的北京时间互不干扰——适合不同厂商错峰时段公布时区不一致的场景。

## 常见问题（FAQ）

| 问题 | 解答 |
| --- | --- |
| 填了模型名但没生效？ | 检查该模型是否已在**麦麦模型配置页**定义过；名字须**完全一致**（区分大小写、前后空格）。 |
| 跨午夜时段怎么写？ | 直接写 `start = "22:00"`、`end = "06:00"`，插件原生支持。 |
| 只想工作日生效？ | 「生效星期」加一项 `weekday`（周末为 `weekend`，或 `["mon","fri"]` 指定）；留空 = 每天。 |
| 「生效星期」里该填什么词？ | 每个项目填**一个**词：`weekday` / `weekend` / `mon`、`tue`…`sun` / `周一`…`周日`（大小写不限）。**不要写 `mon-sun` 这种连字符写法**（会失效）；列表留空 = 每天。 |
| 「生效任务」能填 planner 吗？ | 不能。本插件仅作用于 replyer（回复生成），官方钩子不支持为其他任务指定模型。 |
| 不想干预某些时段？ | 不写覆盖该时段的规则即可——无规则命中的时段默认不干预。 |
| 插件开着但没配规则？ | **零干预**，行为与未安装时完全一致（若 `default_model_name` 留空）。 |
| 多条规则都命中用哪条？ | 按配置顺序取**第一条**命中的。 |
| 改了配置要重启吗？ | 改 `config.toml` 即时生效。改 `plugin.py` 需重载插件或重启麦麦；仅改 `_manifest.json` 必须完整重启。 |
| 手动编辑 config.toml 后报 TOML 解析错误？ | 文件带了 UTF-8 BOM（PowerShell 的 `Set-Content -Encoding UTF8` 会写入），用无 BOM 的 UTF-8 保存即可。 |
| 插件出错会影响回复吗？ | 不会。只记日志不阻断回复（`ErrorPolicy.SKIP`），最坏情况等同于插件不存在。 |

## 注意事项

- `model_name` 指向的模型必须**先在麦麦模型配置页定义**，否则指派无效或导致请求失败；
- 模型名须与配置页**完全一致**；
- 本插件仅作用于 **replyer（回复生成）** 任务，planner 等其他任务的模型不受影响；
- 钩子中指定 `model_name` 会**绕过**麦麦原生的随机/均衡模型策略；
- `timezone_offset`（通用页）按你所在时区设置，北京时间为 `8`；单条规则按其他时区解释时，关闭该规则的「跟随全局时区」并单独设置（支持半小时区如 `5.5`），星期判断同样按规则时区；
- 指定模型请求失败后的重试轮，插件不再指名（交还麦麦的策略兜底），避免反复请求刚失败的模型；
- 错峰时段边界以模型服务商官方公告为准（DeepSeek：空闲=高峰半价，高峰=北京时间周一至周五 9:00-12:00、14:00-18:00；如有调整请同步修改规则时间）；
- 建议为每条规则填写 `note` 备注，方便日后维护。

## 卸载

1. 将 `[plugin]` 的 `enabled` 设为 `false`（或直接停用插件）；
2. 确认麦麦回复恢复正常后，删除插件文件夹；
3. 重启麦麦完成卸载。
